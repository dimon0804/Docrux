# Презентация «Докрукс»: текст по слайдам

Десять слайдов, как требует кейс. На каждом слайде одна мысль. Цифры взяты из замеров в README; перед защитой их стоит сверить с последним прогоном.

Оформление: фирменный зелёный банка `#50b848`, тёмно-серый текст `#1d1f26`, светлый фон `#f5f6fa`, шрифт Inter. Знак проекта — белый лист с загнутым углом и зелёной четырёхлучевой искрой в зелёном скруглённом квадрате (`docs/logo.svg`). Название сложено из document и crux, «суть»; слоган «ИИ, который видит документ насквозь». Скриншоты лежат в `docs/screenshots`.

## 2. Что болит

Студент присылает фото справки и спрашивает: «Подойдёт?»

Секретарь читает снимок, вручную переносит данные, ищет нужный пункт в Положении и пишет ответ. Студент ждёт. Если чего-то не хватает, круг повторяется.

Мы убираем из этого круга всё, что можно сделать без человека.

*Картинка: три шага из кейса — фото, ручная сверка, поздний ответ.*

---

## 3. Что делает «Докрукс»

Один проход, несколько секунд:

1. **Читает снимок.** Выравнивает фото и распознаёт текст.
2. **Заполняет карточку.** ФИО, даты, номер, подпись, печать. Чего нет, того нет: «не найдено».
3. **Отвечает со ссылкой.** Называет пункт Положения или поле документа, на которое опирается.

Решение всегда остаётся за сотрудником деканата.

*Картинка: `docs/screenshots/result-light.png`.*

## 4. Демо: три документа

| Документ | Что увидит студент |
| --- | --- |
| Справка об обучении, всё заполнено | «Документ содержит все обязательные сведения по пунктам 3.1, 3.2, 3.3» |
| Заявление на отпуск без даты | «Не хватает: дата заявления (п. 4.1)» |
| Справка о практике без подписи и печати | «Не хватает: подпись руководителя (п. 5.2), печать организации (п. 5.3)» |

Нажатие на пункт показывает его текст. Нажатие на поле подсвечивает место на снимке.

*Картинка: три маленьких скриншота рядом.*

## 5. Когда ответа нет

«Какой размер стипендии положен студенту?»

> В документе и в Положении нет информации для ответа на этот вопрос. Обратитесь в деканат.

Сервис не сочиняет. Ответ на проверочные вопросы собирает код, а не языковая модель: значение берётся из карточки, пункт из Положения. Вопрос о том, чего в источниках нет, получает отказ.

*Картинка: фрагмент диалога с пометкой «Ответа в источниках нет».*

## 6. Качество в цифрах

Автопроверка организаторов, распознавание по изображениям:

| Набор | Поля | Проверка | Вопросы |
| --- | ---: | ---: | ---: |
| Открытый набор, 30 документов | 1.000 | 1.000 | 1.000 |
| 90 своих документов в том же оформлении | 1.000 | 1.000 | 1.000 |

Свои документы мы сгенерировали с другими фамилиями, вузами и номерами. Так мы убедились, что сервис читает документ, а не помнит открытый набор.

Результат воспроизводится в CI на GitHub при каждом изменении кода.

## 7. Бонусы: все четыре

- **Тип определяется сам.** И для бланка, и для справки, написанной сплошным текстом.
- **Плохие снимки.** Наклон до 30°, тень, блик, низкое разрешение, фото листа на столе: на всех 630 испорченных снимках 1.000 по полям, проверке и ответам.
- **Новый тип без кода.** Один YAML-файл с полями и метками.
- **Подсветка на снимке.** Видно, откуда взято каждое значение.

*Картинка: фото «до» и выровненный снимок «после».*

---

## 8. Сверх задания

- Справки свободной формы: «Дана Петровой Анне Сергеевне в том, что…». ФИО приводится к именительному падежу.
- Документы других типов не отвергаются: сервис показывает текст и найденные строки и объясняет, почему проверить их по Положению нельзя.
- Многостраничные PDF.
- Вопросы по самому Положению: «Нужна ли печать на заявлении?» → цитата п. 4.3.
- Тёмная тема, адаптация под телефон, политика конфиденциальности.

## 9. Как устроено

**Стек.** Tesseract 5 с точной русской моделью, OpenCV, FastAPI, React, Caddy, Docker Compose. Всё работает на процессоре обычного ноутбука, внешние API не используются.

**Приватность.** Файл обрабатывается в памяти и не сохраняется. Базы данных нет.

**Безопасность.** Контейнеры без прав администратора, файловая система только для чтения, строгая Content-Security-Policy, ограничение частоты запросов, проверка файлов по содержимому.

**Запуск.** `docker compose up --build` или ноутбук в Google Colab.
