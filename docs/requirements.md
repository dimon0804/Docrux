# Соответствие требованиям кейса

Каждое требование из презентации кейса, README стартового пакета и Положения, где оно реализовано и чем проверено. Тесты лежат в `backend/tests`, задачи CI описаны в `.github/workflows/ci.yml`.

## Базовый уровень

| Требование | Где реализовано | Чем проверено |
| --- | --- | --- |
| Принять JPG, PNG или PDF и вопрос на русском | `imaging/loader.py`, `api/app.py` | `test_api.py`: приём, отказ для чужих форматов, пустых и слишком больших файлов |
| Распознать текст с помощью OCR | `ocr/tesseract.py`, Tesseract 5 с моделью `tessdata_best` | задача CI «OCR accuracy»: 30 изображений открытого набора |
| Заполнить карточку, пустое поле — «не найдено» | `extraction/fields.py`, `pipeline.py` | `test_open_set.py`: точность полей 1.0 |
| Ответить по полям документа и пунктам Положения | `qa/intents.py`, `qa/answerer.py` | `test_open_set.py`: 120 вопросов, совпадение 1.0 |
| Указать источник: пункт или поле | `qa/answerer.py` | сравнение `sources` с эталоном в автопроверке |
| Не выдумывать, честно сказать об отсутствии ответа | словарная защита в `qa/intents.py` и `qa/retrieval.py` | `test_intents.py`, `test_freeform.py`: более 40 вопросов не по теме получают отказ |
| Тип документа можно выбрать вручную | переключатель типа в интерфейсе, параметр `doc_type` в API | `test_api.py` |
| Интерфейс: веб-страница | `frontend/` | задача CI «Full stack»: разбор документа через шлюз |

## Три вида ответов

| Вид | Формулировка | Основание |
| --- | --- | --- |
| Документ в порядке | «Документ содержит все обязательные сведения по пунктам … Положения. Окончательное решение примет сотрудник деканата.» | п. 6.1 |
| Чего-то не хватает | «Не хватает: … (п. …). Эти сведения обязательны по пунктам … Положения.» | п. 6.2 |
| Ответа нет | «В документе и в Положении нет информации для ответа на этот вопрос. Обратитесь в деканат.» | п. 6.3 |

Согласованность текста ответа со структурным значением проверяет `test_answer_text_agrees_with_structured_value`.

## Формат results.json

| Требование README пакета | Чем проверено |
| --- | --- |
| Верхний уровень: `version: "1.0"` и массив `documents` | схема организаторов, `test_results_follow_the_organizers_schema` |
| У записи ровно пять полей, в `fields` все ключи типа | `evaluate.py` и схема |
| Даты в `ГГГГ-ММ-ДД`, курс строкой с целым числом | `test_textnorm.py`, точность полей 1.0 |
| Флаги подписи и печати логического типа | схема |
| `validation`: статус, пропуски, пункты требований | `test_rules.py`, совпадение проверки 1.0 |
| Вопрос о комплектности: `value` равен статусу, источники совпадают с проверкой | `test_open_set.py` |
| Вопрос о поле: нормализованное значение и `field:<ключ>`; для пустого поля отказ | `test_open_set.py` |
| «Кто принимает решение»: `сотрудник деканата`, `rule:1.3` | `test_open_set.py` |
| Пустые `sources` только при `answerable: false` | схема, `test_answer_text_agrees_with_structured_value` |
| Прогон не срывается из-за одного файла | `test_one_broken_file_does_not_stop_the_batch` |

## Положение

| Пункт | Как соблюдается |
| --- | --- |
| 1.3. Сервис не сообщает «документ принят» и ничего не оформляет | в каждом ответе о комплектности стоит «Окончательное решение примет сотрудник деканата» |
| 2.1. Источники только документ и Положение | внешние API не используются, языковая модель ответы не пишет |
| 2.2. Нельзя дополнять значения предположениями | пустое поле бланка не заполняется из другого места документа; рукописное чтение без подтверждения не попадает в карточку |
| 2.3. Слова «Подпись» и «М.П.» не являются отметкой | распознанный текст вычитается перед поиском рисунка, `imaging/marks.py` |
| 2.5. Даты в формате ГГГГ-ММ-ДД, периоды раздельно | `textnorm.parse_date`, составные поля в конфиге типа |
| 4.3. В заявлении нет поля печати | в описании типа `academic_leave_application` его нет |
| 6.5. Проверка без вопроса | если вопрос не задан, выполняется стандартная проверка комплектности |

## Ограничения кейса

| Ограничение | Как соблюдается |
| --- | --- |
| Ресурсы обычного ноутбука или бесплатного Colab | всё работает на процессоре, одна страница около секунды; есть ноутбук для Colab |
| Бесплатные OCR-библиотеки | Tesseract |
| Внешние API запрещены | их нет; контейнер API не имеет выхода в интернет |
| Инструменты перечислены в README | раздел «Инструменты и модели» |
